# FluentRead v0.0.38 — openai responses

本版本由 [windsyu/FluentRead Fork](https://github.com/windsyu/FluentRead) 发布，不是上游官方商店发行。扩展版本 `0.0.38`，用户脚本版本 `2.0.2`。

## 更新

- 新增独立翻译供应商 `openai responses`，支持官方 Responses 接口及兼容的自建 New API；原有 OpenAI、New API 和自定义 Chat 服务保持不变。
- 支持根地址、版本 Base URL 和完整端点，统一请求、缓存与凭据身份，保留查询参数并提示 `/response` 拼写错误。
- 原生构造 `instructions` 和数组 `input`，强制 `stream: true`、`store: false`；高级请求体拒绝 `messages`，过滤不适用的采样及输出上限字段。
- 共用 SSE 解析器处理分片 UTF-8、文本增量与完成/失败/未完成事件，完整译文完成后再展示；连接检查和实际翻译使用相同调用链。
- 修复同值配置广播使连接检查错误失效的问题，保留真实配置变化、失活和取消时的旧结果隔离。

## 下载与使用

从本 Fork 的 [v0.0.38 Release](https://github.com/windsyu/FluentRead/releases/tag/v0.0.38) 下载对应资产：

| 资产 | 用途 |
| --- | --- |
| `fluent-read-0.0.38-chrome.zip` | Chrome 开发者模式解压加载 |
| `fluent-read-0.0.38-edge.zip` | Edge 开发者模式解压加载；使用无 Chrome manifest key 的专用构建 |
| `fluent-read-0.0.38-firefox.zip` | Firefox 临时加载/自行审查；未经过 AMO 签名，不能作为普通商店安装包 |
| `fluent-read-0.0.38-sources.zip` | 扩展构建及 Firefox 审查源码；完整仓库源码也可从 Release 标签获取 |
| `fluent-read.user.js` | 用户脚本 `2.0.2`；浏览器脚本管理器运行尚未实机验收 |
| `SHA256SUMS-v0.0.38.txt` | 下载资产的 SHA-256 校验清单 |

Chrome/Edge 解压后，在扩展管理页开启开发者模式并加载解压目录。设置中选择 `openai responses`，填写自己的接口地址、模型名和 Key。配置不与其他供应商共享；已有用户首次使用需要单独填写。官方地址默认为 `https://api.openai.com/v1/responses`，自建服务可填根地址。不要把密钥写入高级请求体、公开日志或仓库。

## 验证与限制

- 新版本 405 项协议/配置专项、984 项回归、21 项发布元数据/manifest 专项、测试审计和类型检查通过。
- Chrome、Edge、Firefox ZIP 和用户脚本构建及 verifier 通过；新版本隔离 Chrome + 本机 SSE 夹具 8 项通过，旧 Chat 回归通过。
- 发布前生产 Chrome 已连接用户授权的真实自建 New API，根地址、`/v1`、完整 `/v1/responses` 的连接检查与新段落网页翻译均通过；最终验收为 16 个成功 SSE 请求及 1 个预期 401，恢复/重译、配置重开和失败后重试通过。版本更新只改变版本元数据；没有重新消耗真实服务请求。
- 页面导航取消后无迟到译文，下一请求成功，但没有观察到上游 socket 提前断开。离线测试覆盖 reader、监听器、调度槽位及超时释放。
- Firefox 实机和用户脚本管理器尚未验证。全仓存在已复现于未修改基线的无关失败，不能宣称全仓测试全绿。详细范围及覆盖率边界见[脱敏验收记录](https://github.com/windsyu/FluentRead/blob/v0.0.38/docs/reports/openai-responses-20261010.md)。

本次不提供阅读/写作助手会话、工具调用、图片识别或页面逐字展示。发布资产不包含用户凭据、实测配置、浏览器 profile 或原始实测证据；未向 Chrome/Edge/Firefox 商店提交。
